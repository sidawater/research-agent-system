# AI研究助手桌面应用开发文档

## 1. 页面结构

### 1.1 整体布局

应用采用三栏式布局设计，包含顶部标题栏、主内容区域和底部状态栏。

```
┌─────────────────────────────────────────────────────────────┐
│                         顶部标题栏                           │
├─────────────────────────────────────────────────────────────┤
│ 左侧边栏 │         中间主面板          │      右侧边栏       │
├─────────────────────────────────────────────────────────────┤
│                         底部状态栏                           │
└─────────────────────────────────────────────────────────────┘
```

### 1.2 顶部标题栏

顶部标题栏包含应用标题和功能按钮：

- 应用标题：AI研究助手
- 设置按钮：打开应用设置对话框
- 帮助按钮：打开帮助信息对话框

### 1.3 左侧边栏

左侧边栏宽度占整个页面的20%，最小宽度280px，最大宽度320px，包含对话记录面板：

- 对话记录列表：显示历史对话记录，支持新建对话
- 每条记录显示标题和时间

### 1.4 中间主面板

中间主面板是主要内容区域，包含三个选项卡：

#### 1.4.1 对话选项卡
- 聊天消息显示区域：显示用户和AI的对话内容
- 欢迎信息：应用初次使用时的引导信息
- 动作状态显示：显示当前正在进行的操作状态
- 聊天输入区域：
  - 清空对话按钮
  - 多行文本输入框
  - 导出报告复选框（隐藏）
  - 发送按钮

#### 1.4.2 报告预览选项卡
- 报告标题显示
- 编辑按钮
- 报告内容显示区域
- 报告编辑区域（默认隐藏）

#### 1.4.3 文献预览选项卡
- 文献标题显示
- 文献内容预览区域

### 1.5 右侧边栏

右侧边栏宽度占整个页面的25%，包含三个面板：

#### 1.5.1 对话状态面板
- 连接状态显示
- 当前会话信息
- 进度条显示

#### 1.5.2 报告标题面板
- 报告标题列表
- 导出报告按钮

#### 1.5.3 参考文献面板
- 参考文献数量显示
- 参考文献列表
- 每条文献显示标题、类型标签、摘要、作者和年份

### 1.6 底部状态栏

- 状态信息显示
- 版本信息显示

### 1.7 对话框

#### 1.7.1 设置对话框
- 服务端连接设置：
  - WebSocket服务器地址
  - API服务器地址
  - API密钥
  - 测试连接按钮
- 文件导出设置：
  - 导出目录选择
- 界面设置：
  - 主题选择（浅色、深色、跟随系统）

#### 1.7.2 帮助对话框
- 应用信息显示
- 使用指南
- 快捷键说明

## 2. 对话逻辑

### 2.1 WebSocket连接管理

应用通过WebSocket与后端服务进行实时通信：

1. 应用启动时自动连接WebSocket服务器
2. 连接成功后更新状态为"已连接"
3. 连接失败时显示错误信息，并尝试每5秒重连一次
4. 用户可在设置中修改WebSocket服务器地址

### 2.2 消息处理流程

#### 2.2.1 用户发送消息
1. 用户在输入框中输入研究问题
2. 点击发送按钮或按Ctrl/Cmd+Enter发送消息
3. 消息通过WebSocket发送到后端
4. 显示用户消息在聊天界面
5. 禁用发送按钮，显示处理状态

#### 2.2.2 接收AI响应
1. 后端通过WebSocket发送响应消息
2. 根据消息类型处理不同内容：
   - 状态更新消息：显示处理进度
   - 研究结果消息：显示研究报告内容
   - 参考文献消息：更新参考文献列表
3. 实时更新聊天界面显示AI响应

#### 2.2.3 消息类型处理
- 文本消息：普通文本内容显示
- 引用消息：带有引用标识的特殊样式
- 代码消息：使用代码样式显示
- 状态消息：更新进度条和状态信息

### 2.3 会话管理

1. 每次新建对话生成唯一会话ID
2. 支持查看历史对话记录
3. 当前对话状态实时显示在右侧边栏

### 2.4 报告生成与导出

1. AI响应中包含研究报告内容
2. 报告内容同时显示在报告预览选项卡
3. 报告标题显示在右侧边栏
4. 用户可导出完整报告（包括内容和参考文献）

## 3. 开发、构建、测试

### 3.1 开发环境

#### 3.1.1 技术栈
- Electron：桌面应用框架
- HTML/CSS/JavaScript：前端界面技术
- Node.js：运行时环境

#### 3.1.2 项目结构
```
ui/
├── main.js              # Electron主进程
├── preload.js           # 预加载脚本
├── package.json         # 项目配置和依赖
├── config.json          # 应用配置文件
├── src/                 # 前端源码
│   ├── index.html       # 主页面
│   ├── renderer.js      # 渲染进程逻辑
│   ├── style.css        # 样式文件
│   └── components/      # 组件目录
├── references/          # 参考文献目录
└── exports/             # 报告导出目录
```

#### 3.1.3 启动开发环境
```bash
npm install  # 安装依赖
npm start    # 启动开发环境
npm run dev  # 启动开发环境（带调试工具）
```

### 3.2 构建

#### 3.2.1 构建命令
```bash
npm run build  # 构建完整安装包
npm run pack   # 构建可运行的应用目录
```

#### 3.2.2 构建配置
- 使用electron-builder进行打包
- 应用ID：com.yourcompany.research-assistant
- 输出目录：dist/
- 包含文件：
  - main.js
  - preload.js
  - src目录下所有文件
  - references目录下所有文件
